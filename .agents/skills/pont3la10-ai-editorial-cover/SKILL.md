# Portadas editoriales de Pont3la10

**No usar ImageGen ni entregar imágenes generadas por IA en la automatización
editorial programada.** Juan fijó como regla permanente que cada borrador debe
llevar una fotografía real, pertinente y diferente, con crédito y fuente
verificables. Esta regla prevalece sobre cualquier instrucción histórica de
esta skill que describa una portada generada por IA.

Si la skill `pont3la10-auto-cover` no encuentra una foto adecuada con crédito y
fuente verificables, conserva el expediente y el borrador como candidato
incompleto, registra el bloqueo y continúa con otra oportunidad. No subas una
imagen, no entregues una propuesta CMS para ese candidato y no sustituyas la
foto con una ilustración, montaje, recreación fotorrealista, captura de pantalla
o imagen generada. Nunca uses `coverMediaId: null`.
