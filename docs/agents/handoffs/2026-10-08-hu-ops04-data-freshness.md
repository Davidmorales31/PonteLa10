- **Objetivo de la sesión:** Implementar HU-OPS-04 para mostrar vigencia de datos de fútbol, excluir páginas programáticas sin calidad mínima y ofrecer un chequeo operativo privado.
- **Completado:** Se centralizaron los umbrales y estados de frescura. Partidos, equipos, temporadas/competiciones y jornadas usan el control para indexación. Las fichas de partido, equipo, competición y tablas de Liga Colombiana presentan aviso de datos vencidos; el panel Operación incorpora conteos agregados de calendario/tablas por competición.

- **Decisiones:** `checked_at` es la verificación existente; no se añade migración/columna. Umbrales: en vivo 3 min, prepartido (hasta 90 min antes) 30 min, calendario 36 h, aplazado/suspendido/reprogramado 90 min, tabla 60 min. Finalizados/cancelados/abandonados con fecha válida son estables para preservar archivos históricos que el worker ya no consulta. El endpoint agregado requiere `configuracion.ver`, usa cliente Supabase de sesión con RLS, limita filas y datos devueltos y responde `private, no-store`; no usa `service_role` ni contacta proveedores.
