- **Decisiones:** guardas contra regresión: performance ≥0,45, LCP ≤9 s, CLS ≤0,30 y TBT ≤800 ms (mediana de tres muestras); runners de Lighthouse fijados a Ubuntu 24.04 en PR #117. Objetivos ideales de campo: LCP ≤2,5 s, INP ≤200 ms y CLS ≤0,1 en p75. TBT solo detecta bloqueos del hilo principal; no se presenta como INP. No se agrega anuncio ni telemetría nueva porque podrían empeorar CWV o exceder las preferencias actuales.

Se calibraron los límites; el CI final `37751820428` y reporte Production `37752052200` pasaron. Production final: `/` score 0,71/LCP 6,903 s/CLS 0/TBT 187 ms; `/partidos-hoy` 0,70/4,216 s/0,20/245 ms; `/liga-colombiana` 0,75/3,347 s/0,01/580 ms; `/colombianos-en-europa` 0,73/5,429 s/0,06/264 ms. PageSpeed Insights respondió 429 (cuota cero), así que no hay datos CrUX/INP de campo. Lighthouse no pudo autoarrancar Edge en Windows; GitHub Actions generó los reportes con Chrome. El build conserva warning upstream `[DEP0155]` de `@vue/shared`.
- **Pendientes:** los objetivos ideales de campo aún no están verificados y LCP/CLS requieren una HU de optimización separada; no afirmar que los objetivos p75/INP están alcanzados. La protección impidió inspeccionar contenido del Preview desde las conexiones de esta sesión, aunque Vercel marcó los deploys verdes.
