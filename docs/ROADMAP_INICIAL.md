# Roadmap inicial

## Fase 0 - Fundacion

- Crear base Nuxt 3.
- Aplicar identidad visual.
- Definir dominios internos.
- Documentar seguridad y decisiones tecnicas.
- Preparar configuracion Supabase.

## Fase 1 - Web publica

- Home.
- Listado de articulos.
- Detalle de articulo.
- Categorias.
- Especiales.
- SEO basico.

## Fase 2 - Panel editorial

- Login admin.
- Dashboard editorial.
- Crear, editar y publicar articulos.
- Estados: borrador, revision, programado, publicado, archivado.
- Imagen destacada.

## Fase 3 - Redes internas

- Asociar piezas sociales a cada publicacion.
- Generar formatos por red social desde el panel.
- Preparar integraciones futuras por API.

## Fase 4 - IA asistida

- Ideas.
- Titulos.
- Borradores.
- Descripciones SEO.
- Copy para redes.
- Aprobacion humana obligatoria.

## Fase 5 - Primer modulo interactivo

Recomendacion: empezar por Simulador Mundial por impacto visual, facilidad para compartir y menor complejidad inicial que album o polla.
